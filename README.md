# 半导体研究知识库 · Semiconductor Atlas

一个长期化、可交互的中文半导体专题知识库，分**两条轨道**。纯前端静态站、无构建、可离线打开。

## 🔗 在线访问
GitHub Pages：<https://jxnchj.github.io/semiconductor-lab/>

进入是**选轨门户**（`index.html`），选一条轨道：

- **第一轨 · 原理科普** → `principles/` —— 芯片制造原理**交互图解**（16 章）：晶体管 / 反型层、光刻（含光刻胶感光机制）、先进制程（FinFET · GAA · CFET · 背面供电）、制造流程（含 CMP、电子特气）、硅片·掩膜、存储器、先进封装、功率 / 化合物半导体。
  - **内嵌 4 个 Three.js 3D 交互场景**（库已内联，离线可用）：
    - 晶体管架构演进：平面 MOSFET → FinFET → GAA 纳米片（B1/B2 章，剖切 / 透视 / 通电演示）
    - 3D NAND 存储塔（D2 章：字线堆叠剖切、读 0/读 1 通电演示、宏观阵列协同读出）
    - CoWoS 2.5D 先进封装爆炸图（C9 章：五层爆炸、TSV/RDL、数据/供电通路点亮）
    - EUV 六镜光路（C4 章：点亮光路看能量逐镜衰减、掩膜台 4:1 同步扫描）
- **第二轨 · 产业链价值** → `atlas.html` —— **研究终端**（14 页），覆盖**七大赛道**（材料 / 设备 / 晶圆制造 / 封装测试 / EDA·设计 / 存储器 / 功率半导体）+ 政策时间线 / 估值框架 / 风险框架 / 需求结构等投研工具。配**全局搜索**与**上市公司速查（66 家）**。投研视角，数据**标来源与时间**、区分「事实 vs 厂商叙事」。

## ✨ 站点特性
- **11 套主题**（含经典暗夜），两轨共享，一键切换
- 自托管中文字体（`principles/fonts/`），离线排版一致
- 深链直达：`principles/index.html#/章` 或 `#/章:小节锚点`（如 `#/pkg:cowos-3d`）
- **SOX 费城半导体指数回撤指标每日自动更新**（本地定时任务抓取后重写页面标记块，随 push 上线）
- 每页右上角「更新日志」查看版本沿革
